# 超级小爱增强

这是一个严格使用 Modern libxposed API 102 的 LSPosed 模块，为超级小爱提供 Agent 完整轨迹、
System Prompt 补丁、模型首次输出超时和目录级文件权限增强。模块不会修改或重签名超级小爱 APK。

从 `1.6.0` 起，模块不再注入或管理第三方 MCP。超级小爱 `8.2.3.1619` 已提供原生第三方 MCP，
应直接使用目标应用的设置；从旧版模块升级时，首页可将原有服务器配置复制为原生 JSON。

## 兼容性

- 目标包：`com.miui.voiceassist`
- 增强功能最低目标版本：`8.0`（按 `versionName` 主版本判断）
- 原生第三方 MCP 最低版本：`8.2.3.1619`
- 已验证快速路径参考版本：`8.0.30.4121`（versionCode `508000030`）
- Xposed API：`minApiVersion=102`、`targetApiVersion=102`
- 不兼容经典 LSPosed 1.9.x

参考版本优先使用已验证方法签名；其他 `8.0+` 版本会通过 DexKit 候选提示和结构规则独立解析
Prompt、Agent Trace、首次输出超时及文件策略目标。只有候选唯一且结构完整时才安装对应 Hook；
某项无法可靠匹配会保持宿主行为，不影响其他已匹配能力。

`8.0` 至 `8.2.3.1619` 之前的目标仍可使用非 MCP 增强，但模块不再为其补回第三方 MCP。

## 构建

需要 JDK 21、Android SDK 37 和 Build Tools 36.0.0：

```sh
./gradlew --no-daemon testDebugUnitTest lintDebug assembleDebug
```

产物位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 使用

1. 安装模块 APK，在支持最终 API 102 的 LSPosed 运行时中启用模块。
2. 作用域只选择“超级小爱”（`com.miui.voiceassist`），然后结束并重新启动超级小爱进程。
3. 打开模块 App，确认框架和目标版本状态。
4. 配置所需的 Agent、Prompt、超时或文件权限增强；标注“重启后生效”的设置需重启超级小爱。

首页右上角的重启按钮需要 root 权限。确认后模块会通过 `am force-stop` 结束超级小爱的全部进程
再重新打开；正在进行的对话、模型响应和工具调用会立即中断。

### 旧版 MCP 配置迁移

升级至 `1.6.0` 后，模块不会再合并 MCP 配置、捕获宿主 MCP 管理器或触发在线重载。
如果 Remote Preferences 中仍有旧服务器，且已安装支持原生 MCP 的目标版本，首页会显示迁移提示和
“复制原生 MCP JSON”入口；旧目标上只保留数量提示，升级后才允许复制：

1. 点击复制；
2. 打开超级小爱原生的“设置 → MCP 服务”；
3. 按原生界面导入或填写配置，并自行验证服务器连接和工具发现结果。

导出内容可能包含 Authorization、API Key 等请求头。它只会在用户明确点击后写入系统剪贴板，
请迁移完成后清除剪贴板，不要把配置粘贴到不可信应用或公开日志。旧数据暂时只读保留，模块不再使用它发起连接。

### Agent 完整轨迹

开启后，模块沿用超级小爱现有思考过程卡片显示公开 reasoning，并为工具摘要增加输入、输出、
错误、耗时和元数据详情。开关默认开启，切换后需重启目标进程。

模块只修补自身 code cache 中的私有 RN bundle 副本；宿主 bundle 结构不唯一或不兼容时直接回退。
私有 bundle 缓存最多保留 3 个版本。尚未收到终态事件的工具调用记录按最近使用顺序最多保留
512 条，并在 30 分钟后过期，避免后台长会话无限保留工具参数。

### System Prompt 补丁

“System Prompt 补丁”会在宿主读取 Agent Prompt、工具说明和记忆模板时执行内存中的精确文本替换，
不会覆盖超级小爱的私有文件。规则可逐条编辑、停用或删除，并可在当前安装 APK 上预览差异。

查找原文必须恰好出现一次；零匹配或多匹配会跳过该规则并记录不含正文的诊断信息。
所有规则按列表顺序执行。该功能不修改 DirectPath 快捷执行、运行时硬编码规则或动态生成的其他上下文。

### 模型首次输出超时

“模型首次输出超时”可选择：

- 跟随宿主；
- 自定义大于 0 的整数秒；
- 不限制这一层首次可见输出 watchdog。

正文增量、完整工具调用或模型结束事件算作首次可见输出，公开 reasoning 本身不算。
该设置不修改宿主的流式空闲超时、单次请求绝对上限或工具自身超时。

### 文件访问权限

目录规则可分别授权：既有文件删改、锁屏读取、锁屏新建或删改、后台/定时 Agent 删改，
以及锁屏命令递归删除。每条规则还可保留每次确认，或仅对匹配目录的后台/全部 Agent 自动确认。
短信、电话、邮件等非文件风险类别不受影响。

规则只接受 `/sdcard` 或等价的 `/storage/emulated/0` 绝对路径，并统一规范化到同一命名空间。
运行时采用最长目录匹配；更具体的子目录可覆盖上层授权。不存在、越界、歧义或无法规范化的路径均失败关闭。

锁屏 CLI 只支持经过逐命令解析的有限文件命令。路径操作数必须是绝对路径；未知参数、相对路径、
shell 重定向/管道/命令替换、`find -exec`、可执行外部脚本的 `sed` 等均不会自动放行。
`rm -r`、`rm -R` 及短参数组合会被识别为递归删除并要求相应权限。

超级小爱 `8.2.3.1619` 扩展了文件风险确认方法的参数。模块按 continuation、风险上下文 getter、
确认入口和豁免方法的共同结构解析，不依赖旧版固定参数个数；任一候选不唯一时保留宿主确认框。

## 数据与安全边界

- 配置保存在 Xposed 框架 Remote Preferences 中，目标进程只读取模块仍启用的增强配置。
- Prompt 补丁只修改读取结果，不写入宿主资产。
- 文件扩权不会绕过 Android/Linux 权限、Scoped Storage 或文件系统挂载限制。
- 模块不启用宿主全局 `osbot_bypass_tool_confirm`；只评估命中用户目录规则的文件风险操作。
- Root 和 Xposed 框架具有较高权限，目录规则与旧 MCP 凭据应按敏感数据处理。

## 日志与离线诊断

```sh
adb logcat | rg 'XiaoAiMcpBridge'
./scripts/verify-target-apk.sh /path/to/超级小爱.apk
```

日志记录各增强能力的解析来源和安装结果，不记录 Prompt 正文、工具输入输出或旧 MCP 请求头值。
离线脚本只检查自动探测依赖的稳定标记；最终能力以目标进程内的唯一结构解析和运行日志为准。

包名、Java 命名空间和日志 Tag 中的 `mcp` 为历史兼容标识，`1.6.0` 不再包含 MCP 注入能力。
